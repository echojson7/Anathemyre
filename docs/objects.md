# Объекты, заготовки, экземпляры по чанкам

Состояние на 2026-10-31 (шаг 2б, PR 1: механизм и Скудель). Описания: `data/defs/objects.txt`, `data/defs/prefabs.txt`.
Код: `src/defs/objects.c` (разбор), `src/world/objects.c` (экземпляры), `src/content/shapes.c` и `town_build.c`
(формы), `src/view/scene.c` (сетки), `src/view/lights.c` (огни), `src/sim/phys.c` (`phys_static_add`).

## Что это

Постройки и детали локаций больше не код, а данные. Три слоя, как ThingDef с компонентами у RimWorld и
pack-in у Bethesda:

| Слой | Что | Где |
|---|---|---|
| объект (`object`) | форма (генератор по имени), материалы, коробки физики, режим расстановки, свет, точки действия | `objects.txt` |
| заготовка (`prefab`) | список объектов и других заготовок: место, поворот, размер, замена материала, выбор варианта по зерну | `prefabs.txt` |
| экземпляр | номер объекта, место, поворот, размер, материалы, зерно, флаги — 30 байт, структура массивов по чанкам 256 м | `world/objects.c` |

Мир при старте разворачивает заготовку `world`: каждая её строка — локация. Локация = заготовка + зерно: вид
каждого экземпляра (оттенок, износ, мелочь на прилавке) из зерна, раскладка одна. Отличия от заготовок не
сохраняются (решение пользователя: локации тестовые) — экземпляры в сохранение не идут, строятся заново.

Стена, дверь, перекрытие, окно — отдельные экземпляры, а не склеенная сетка: под будущее строительство.

## Объект

| Ключ | Значения | Смысл |
|---|---|---|
| `shape` | имя | генератор формы (`content/shapes.c` — общие, `town_build.c` — части Скудели); без shape объект только светит |
| `size` | x y z, м | размер по умолчанию; строка заготовки может задать свой |
| `mat`, `mat2` | имя материала | слоты 0 и 1 ([materials.md](materials.md)); заготовка может заменить |
| `tint` | доля | разброс цвета по зерну |
| `place` | settle, hang, fixed | как стоит ([physics.md](physics.md#как-вещь-стоит-в-месте)); пока все стоят намертво |
| `shadow` | yes, no | отбрасывает ли тень (нет — в отдельную сетку без теней) |
| `solid` | `full`, `none` или cx cy cz hx hy hz | коробки физики: во весь размер (точка — середина) или в осях объекта при размере по умолчанию; растягиваются с размером экземпляра; до 4 |
| `light` | материал сила, или r g b | свет-компонент: цвет лампы из materials.txt × сила |
| `light_at`, `light_dir` | x y z | точка и ось света в осях объекта, поворачиваются с ним |
| `light_radius`, `light_cone`, `light_glow` | числа | как у `PointLight` ([lights.md](lights.md)) |
| `light_night` | a s | зажигается с темнотой a + s·(зерно); без строки горит всегда |
| `light_flicker` | none, hum | дрожь напряжения и редкие просадки |
| `light_shadow` | yes, no | на будущее: огни пока без своих теней |
| `act` | что x y z поворот | точка действия (торговать, сесть): только поле, логики нет |
| `parent` | имя | первой строкой: копия другого объекта |

## Заготовка

```
prefab skudel
    put house_block -17.3 1.5 -1.4 yaw 180 size 5.12 2.93 6.2 mat concrete_dark
    put crate|barrel|sack 3 0 2          # один из вариантов по зерну
```

`put что x y z [yaw градусы] [size w h d] [mat имя] [mat2 имя]`. Что — объект или заготовка (вложенность до 16,
петли запрещены). У заготовки нет размера. Замена материала у вложенной заготовки — по умолчанию для её частей.
Запись с тем же именем ниже (мод) заменяет список целиком.

Зерно экземпляра — от зерна родителя и номера строки; у мира — от зерна мира.

## Точка экземпляра

| Форма | Где точка |
|---|---|
| коробки (`box`, `paving`, `rubble`, `buttress`, `sand`, окно, заплата) | середина |
| дверь, балкон, водосток, лестница, лачуга, ворота, прилавок, бочки, ящики | низ, у фасада или у земли |
| протяжённые (`fence`, `railing`, `cable*`, `pipe`) | начало; конец — на size.x вдоль +x, выше на size.y |
| стояки (`pipe_up`) | низ; вверх на size.y, радиус size.x |

Оси экземпляра: +z вперёд (от стены к улице), +x вправо, поворот только вокруг вертикали. Наклоны частей
(навес, контрфорс, обломок) — в генераторе, случайные — из зерна.

## Вид, свет, физика

- Вид (`scene.c`) собирает статические пакеты: у каждой локации в каждом чанке свой, отдельно с тенью и без.
  Пакет — одна сетка: вне кадра и вне теней отсекается целиком, как прежде посёлок. В мире `GpuMesh` нет.
- Огни (`lights_collect`, `view/lights.c`) — из экземпляров с `light` ближе 300 м к камере. Вместо
  `scene_hall_lights` и `scene_ring_lights`: лампы зала и свет ринга — объекты `hall_lamp`, `ring_spot`,
  `ring_lamp` в заготовках `hall_lamps` и `ring_lights` (сетки зала и ринга пока в коде, переедут в PR 2).
  Огни Мерильни — `debug_lights` (отладка), факел в руке — `figures.c`.
- Физика (`objects_solids` → `phys_static_add`): коробки объектов, которые стоят намертво. Лом и вещи упираются
  в стены, ярусы, прилавки ([physics.md](physics.md)). Высоты, по которым ходят люди (`town_ground`), пока кодом.

## Скудель

Раскладка перенесена из кода разовым переносом (2026-10-31): та же, что давал код с зерном 1337, — 651 строка
`put`, 60 объектов. Места жителей (`town_spots`, 35) перенесены таблицей. Оттенки и мелочь теперь из зерна
каждого экземпляра: кадр близок к прежнему, но не бит в бит. Экземпляров в мире 660 (19.8 КБ), коробок
физики 367, пакетов 4.

## Новый объект

Только если иначе играется или у него другой силуэт ([props.md](props.md#правило)); оттенок и износ — зерно.
Новая форма — функция в `content/` и строка в таблице форм (`g_common` в shapes.c или таблица локации).
