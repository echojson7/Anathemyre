# Описания вещей и моды

Состояние на 2026-10-30 (этап 6 фундамента). Файлы: `data/defs/*.txt`. Код: `src/defs/deftext.c` (чтение строк,
общее для всех описаний), `src/defs/defs.c` (оружие, броня, вещи, удары, качество), проверка — `tools/defs_check.sh`.

## Что это

Всё, что раньше было таблицами в коде (`items.c`, `inventory.c`, форма оружия в `weapon.c`, голоса в `sfx.c`,
виды одежды в `look.c`), теперь в текстовых файлах. Одна запись на вещь: бой, слот, размер, вид на теле, звук,
форма оружия. Встроенный контент лежит в тех же файлах и в том же формате, что моды: что может игра, то может мод.

Формат свой, как raws у Dwarf Fortress: мод правится блокнотом, без конвертера. JSON или TOML дали бы только
зависимость (правило библиотек, [libraries.md](libraries.md)): разбор — пара сотен строк.

## Файлы

| Файл | Что |
|---|---|
| `weapons.txt` | оружие: числа боя, размер, голос, форма |
| `armor.txt` | одежда и броня: слот, что закрывает, сопротивления, вид на теле |
| `goods.txt` | вещи: еда, хлам, снаряжение без брони (респиратор, ботинки, ранец, пояс) |
| `combat.txt` | удары (сверху, размах, укол) и ступени качества |

Порядок чтения: файлы `data/defs` по алфавиту, затем каждая подпапка `mods/` (рядом с `data`) по алфавиту, в ней
файлы по алфавиту. Флаги `--defs DIR` и `--mods DIR` берут другие папки (проверки).

## Запись

```
weapon ressora          # вид и имя записи
    name "РЕССОРА"      # строки в кавычках
    damage 24 4 12      # ключ и значения через пробел
```

| Правило | Почему |
|---|---|
| заголовок `вид имя`: weapon, armor, goods, attack, quality | имя — латиница, цифры, `_`, короче 32 знаков; по нему код, моды и сохранения находят запись |
| поля до следующего заголовка; отступы не нужны, `#` — комментарий до конца строки | |
| ключи английские, тексты русские | ключи — для мододелов, тексты — для игрока |
| номер вещи — порядок первой записи с этим именем | номер живёт только в памяти, в сохранение идёт имя |
| запись с уже бывшим именем правит только названные поля | мод меняет вес секача одной строкой |
| `parent имя` первой строкой — копия другой записи того же вида, дальше свои поля | как ParentName в RimWorld: новая вещь от старой в три строки |
| числа — свой разбор (`-12`, `0.85`, `.5`), без экспоненты | не зависит от локали и libc: одно и то же число на всех системах |
| ошибка — «ОПИСАНИЯ: файл:строка: что не так» в журнале, игра не запускается | сломанный мод не даёт тихо испорченного мира |
| удары и качество — набор постоянный | моды правят числа и названия, новых не добавляют: их знает код боя |

После всех файлов каждая запись проверяется: у оружия есть name, attacks, targets, size, length, speed и хотя бы
одна часть формы; у брони name, slot, size; у вещи name, size, desc. Ещё проверяются имена, которые код ставит
сам: свой отряд, наборы арены, жители и тестовые сцены (`g_need` в defs.c). Они переедут в файлы вместе
с фракциями.

## Поля

Оружие (`weapon`):

| Ключ | Значения | Смысл |
|---|---|---|
| name | строка | название |
| model | строка | готовая форма из Blender: файл `data/meshes/weapons/<строка>.mesh` ([weapons.md](weapons.md#модели-из-blender)); части формы ниже — запас, если файла нет |
| class | blade, cleaver, blunt, polearm, heavy | навык, хват, ножны ([weapons.md](weapons.md)) |
| attacks | overhead, swing, thrust (любые) | какие удары умеет |
| targets | 1–8 | сколько целей задевает размах |
| damage | режущий дробящий колющий | урон |
| length | м | длина сверх руки 0.7 |
| weight | кг | темп удара и доставания, усталость |
| speed | 1 — быстрое | множитель темпа |
| arc | градусы | дуга размаха |
| knock, pen | число, 0..1 | сбивание; пробой брони уколом |
| size | ширина высота | клетки инвентаря, оружие стоймя |
| voice | слово [слово] | звук, когда им закрылись, и когда им бьют: ressora, sekach, armatura, bagor, hook, balka ([sound.md](sound.md)); голос armatura остался без своей вещи |
| common | yes / no | в общем запасе: отряды, арена, толпа берут случайное оружие только отсюда, по порядку записей |
| unique | yes / no | единственная вещь: вид не зависит от качества |
| paint | материал r g b | цвет и материал частей ниже: concrete, rust, sand, cloth, leather, glyph, emissive, skin, metal, steel (сталь клинка: мелкое зерно, разводы окалины, ржавчина пятнами по качеству вещи) |
| rod | от до радиус сдвиг | стержень вдоль оружия, м от кулака |
| box | от до ширина толщина сдвиг наклон | брусок: ширина к лезвию, сдвиг к лезвию, наклон в плоскости лезвия |
| blade [плоскость подводка], затем st | st: ось обух лезвие толщина толщина_обуха ребро | клинок протяжкой по станциям: где по +Z обух и лезвие, толщина у ребра и у обуха (половина, м), ребро 0..1 от обуха к лезвию; толщина обуха 0 — обоюдоострый. Сечение из 17 точек: обух со скосами, плоскость, дол, линия спуска, узкая подводка у кромки. Плоскость — доля полуширины обоюдоострого без спуска (0 — ромб), подводка — ширина светлой заточенной кромки, м. Грани оттенены: подводка светлее и чище, дол темнее, спуск чуть светлее плоскости |
| fuller | от до ширина глубина | дол последнего клинка: сходит на нет у концов |
| plate толщина, затем pt и bumps | pt: пары «ось к_лезвию»; bumps: от до к_лезвию сколько выступ | пластина по контуру; bumps — полукруглые зубцы (выступ меньше нуля — выемки) |
| hole | ось к_лезвию полуось полуось | овальная прорезь в пластине, сразу после plate или другой hole |
| wrap | от до радиус витков [ширина наклон] | обмотка рукояти: ширина — доля шага под витком (0.8; 0.97 — внахлёст, 0.5 — шнур с просветами), наклон витка (0.32; 0 — кольца) |
| knob | от до радиус сдвиг [граней форма] | навершие, кольцо, муфта: граней 8 (6 — гайка), форма 0 бочонок, 1 шайба, 2 шар |

Форма: кулак правой руки в начале координат, остриё по +Y, лезвие по +Z, толщина по X. Первая часть формы в записи
заменяет форму родителя или встроенную целиком. До 48 частей и 1536 чисел точек на оружие, до 64 видов оружия.
Сетки строятся при старте, на каждую вещь три вида по качеству (см. [weapons.md](weapons.md#качество)).

Броня (`armor`): name; slot (head, face, shirt, armor, legs, feet, hands, back, belt, pants); cover — пары
«часть доля» (head, chest, stomach, arm_l, arm_r, leg_l, leg_r; не названные — 0); resist — три сопротивления;
weight; dodge_penalty; size; look — сетка на теле (rags, quilt, jacket, plate, bucket, greaves, wrap, boots,
mitts, pack, belt, pants или none); hides — какие сетки под ней не рисуются (`hair` — причёска); metal — удар
звенит железом (`metal no` снимает).

Вещь (`goods`): name, desc, size, stack (1–255), slot (по умолчанию none — только в мешок), weight, carry (кг
к переносимому), look, hides.

Удар (`attack overhead|swing|thrust`): name, damage (множитель), windup (множитель замаха), reach (м), arc
(0 — дуга оружия). Качество (`quality junk|worn|sound|master|ancient`): name, mul.

Сетки одежды новых видов мод пока добавить не может: их делает конвертер (`tools/humanconv`), список
`g_gear_file` в look.c. Новая вещь мода может надеть уже имеющийся вид.

## Сохранения

В начале тела сохранения — имена всех описаний по номерам. При чтении номера вещей в мире (листы людей, бойцы
поля и арены, ростер арены) пересчитываются под нынешние описания. Имени больше нет (мод убран) — «в мире есть
X, а в описаниях такой записи нет», файл не читается, мир не тронут. В сумму мира имена не входят: тот же мир
при другом порядке описаний после пересчёта даёт ту же сумму.

## Проверка

`tools/defs_check.sh` (в CI под ASan):
1. Мир записан со встроенными описаниями, прочитан и записан с описаниями в обратном порядке, прочитан снова со
   встроенными — сумма через минуту та же, что без записи.
2. Мод правит вес секача и добавляет стальную рессору через `parent`.
3. Сохранение с вещью мода без мода не читается.
4. Ошибка в числе в файле мода — файл и строка в журнале, выход с ошибкой.

Перенос таблиц в файлы прошёл бит в бит: суммы арены, поля, отрядов, боя на потоках и кадры те же, что до него.
Штаны получили размер 2×2 (в таблице кода размера не было, 0×0); на суммы это не повлияло.
