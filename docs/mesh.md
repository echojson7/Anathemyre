# Формат .mesh

Сетка детали (`docs/render.md`, «Объекты»). Пишут офлайн-генератор (`tools/meshgen.py`, потом конвертер glTF) и
`tools/meshpack` (кластеры и LOD),
игра только читает (`src/asset/mesh.cpp`). Little-endian, поля по одному, без структур целиком.

`ANAMESH1`, дальше куски «тег (4 байта), версия (u32), длина (u64)» (`src/core/ser.h`); незнакомый кусок
пропускается, поэтому новые куски не ломают старые сетки.

| Кусок | Содержимое |
|---|---|
| `HEAD` 1 | число вершин u32, индексов u32, границы min f32×3, max f32×3 |
| `MATS` 1 | число u32; имена материалов (u8 длина + байты). Номер в вершине — место в этом списке |
| `VERT` 1 | на вершину 20 байт: положение f32×3, нормаль октаэдром с осью y (2×snorm16), материал 0 и 1 (u8), доля смеси (u8, 255 — весь материал 1), затенение (u8, 255 — без тени) |
| `INDX` 1 | индексы u32, тройками |
| `CLUS` 1 | число u32; кластер: первый индекс u32, треугольников u32 (≤ 124), сфера f32×4 |
| `LODS` 1 | число u32; LOD: первый кластер, число кластеров, первый индекс, число индексов (u32), ошибка f32 (м) |
| `COLL` 1 | коллайдер: число u32; коробка — центр f32×3, половины f32×3, кватернион f32×4 |
| `COAR` 1 | грубая форма для света: те же коробки |

- Материал в сетке — **по имени**: при загрузке имена ищутся в таблице материалов игры, неизвестное имя даёт
  «missing» (ярко-лиловый) и предупреждение в журнале.
- Начало координат сетки — середина низа: экземпляр с высотой земли стоит на земле.
- Кластеры ≤ 124 треугольников (≤ 128 вершин) под visibility buffer (25 бит кластер + 7 бит треугольник).
- **`tools/meshpack`** (`meshpack <сырой.mesh> <готовый.mesh>`, C++ с meshoptimizer v1.3, `third_party/meshoptimizer/`):
  сваривает одинаковые вершины, ставит порядок под кеш вершин и выборку, строит цепочку LOD (каждый — упрощение
  предыдущего вдвое по треугольникам с закреплённой границей, ошибка копится, не больше 0.25 м, до 6 уровней,
  цепочка кончается, когда упрощение даёт меньше 15 %) и кластеры каждого LOD (`meshopt_buildMeshlets`, сфера —
  `meshopt_computeMeshletBounds`). `COLL` и `COAR` копирует как есть. Собирается хостовым clang под Linux
  (`make meshes`), флаги без FMA — байты одни на любой машине, CI сверяет.
- **LOD в игре:** самый грубый LOD, у которого ошибка на экране не больше 0.75 пикселя. Кадр мира выбирает его
  на GPU при отсечении (`cull.glsl`) и рисует кластеры этого LOD (выбор LOD видом удалён вместе с forward, 7.11).
- Шаг мира читает только коллайдер (смена сетки или LOD не ломает повтор); сейчас коллайдер ещё никто не читает.
- Заглушки этапа 1 (`cube`, `pillar`, `plate`), камни рассыпки этапа 2 (`rock_a/b/c`: икосфера с одним делением,
  сплюснутая и искажённая хешем, грани плоские, материал `stone`) и детали руины этапа 4 (`tools/meshgen_ruin.py`,
  `docs/ruin.md`) лежат в `data/meshes/` в git. `make meshes` пересобирает их, CI проверяет, что генератор даёт те же байты.
- Начало координат деталей руины — середина низа, кроме висящих: `girder_4` и `beam_broken_*` висят вниз от
  y = 0 (ставятся по низу плиты), `stair_4` начинается у подножия (x = 0) и идёт вдоль +x.
