# Фабрика деталей (`tools/parts`)

Здания и предметы второго поколения (после Остова на коробках `meshgen_ostov.py`). Цель облика — «между Kenshi и
Skyrim»: формы читаются вблизи, края сбиты, у трубы есть раструб и хомут, а не голый цилиндр. Руками сетки никто
не лепит (правило `AGENTS.md`): деталь — **рецепт** на Python, который отдаёт замкнутое тело, а здание — список
операций над телами. Первое здание фабрики — Исподь (`docs/ispod.md`).

    make parts PYTHON=<python с bpy>      data/meshes/ispod_*.mesh
    python tools/parts/preview.py out.jpg --cam x y z --to x y z [--light x y z сила]… [имена сеток]

## Из чего состоит
| Файл | Что |
|---|---|
| `kit.py` | рецепты предметов без Blender: `Body` (грани с материалом), `tube` (труба по ломаной со скруглением и переменным радиусом), `lathe` (тело вращения: раструб, фланец, колпак), `box` (коробка с фаской), `prism` (вытянутый профиль), `blob` (обломок: икосфера с шумом радиуса), `sag` (провис кабеля) |
| `plan.py` | здание как список `("add" \| "cut", Box \| Prism)`; из того же списка — коробки коллайдера (`colliders`) |
| `solid.py` | цельное тело булевыми операциями Blender (`bpy`): глыба − пустоты + лестница − сколы, потом фаска |
| `export.py` | треугольники → `.mesh`: деление длинных рёбер, проверка замкнутости, нормали, порядок вершин, `meshpack` |
| `build.py` | собрать сетки (`make parts`); незамкнутая сетка — ошибка |
| `preview.py` | лист просмотра: кадр тел трассировкой Blender без игры (форма, не свет) |
| `ispod*.py` | раскладка и наполнение Исподи |

## Бетон — одно замкнутое тело
Остов собран из сотен коробок, прижатых друг к другу: на стыках возможны щели и T-стыки, а фаску на ребро из двух
коробок не снять. У фабрики бетон здания — **одна поверхность**: большая глыба, из неё вырезаны зал, тоннель,
коридор и шахта лестницы, добавлены марши и балки, вырезаны сколы на кромках (`blob`), на все рёбра круче 50°
снята фаска 12 мм (модификатор Bevel). Щель между стеной и лестницей невозможна по построению; тени страницами и
поле расстояний (`docs/shadow.md`, `docs/sdf.md`) получают толстые замкнутые стены, которых они и требуют.

- **Решатель — MANIFOLD.** `EXACT` в bpy 5.3.0 даёт разные координаты вершин от запуска к запуску; `MANIFOLD`
  (операнды коллекцией, потом Bevel) — один и тот же набор треугольников при 1, 2 и 4 потоках (замер 2026-11-15,
  16 запусков). Гуляет только порядок вершин и граней — его выравнивает `export.canonical` (треугольник
  начинается с меньшей вершины, список отсортирован), после чего `.mesh` совпадает побайтно.
- **Вне CI.** В CI Blender не ставится, поэтому `make parts` отдельно от `make meshes`, а сетки фабрики CI не
  пересобирает (как ретаргет клипов, `docs/anim.md`). Совпадение байт между машинами не проверено: сетку
  пересобирает тот, кто менял рецепт, и коммитит результат.
- **Материал грани** ставит раскладка по месту и нормали (`ispod.material_of`): пол, низ плит, стены, излом у
  сколов — те же четыре материала бетона, что у Остова (`docs/materials.md`). Узор — в мировых координатах, UV нет.
- **Длинные рёбра** делятся до 2.5 м (`export.subdivide`, середины общие у соседей — тело остаётся замкнутым):
  кластерам и свету по вершинам не нужны треугольники в 80 м.

## Коллайдер из того же описания
`plan.colliders(ops)`: план режется по всем граням тел на клетки (наклонные края — не шире 0.3 м), в клетке по
вертикали считаются отрезки бетона (добавить отрезок — объединение, вырезать — разность), одинаковые отрезки
соседних клеток жадно сливаются в прямоугольники. Выходит набор коробок `COLL` без нахлёстов: у Исподи 337 на
весь бетон, ступени — по коробке на проступь. Свод тоннеля в коллайдере — коробка (третий элемент операции),
кольца обделки не участвуют (`False`). Сколы и фаски коллайдер не видит. Предел коробок одной сетки поднят с 256
до 1024 (`src/app/assets.cpp`).

## Наполнение — рецепты
Трубы, кабели, перила, рельсы — отдельные сетки без коллайдера (`ispod_props.py`), каждая — замкнутые тела из
`kit.py`. Правила, которые дают «не Kenshi»:
- у трубы — раструбы, муфты, фланцы с болтами, хомуты и подвесы там, где они были бы на самом деле;
- кабель провисает между крюками (`sag`), пучок — несколько кабелей разной толщины;
- ничего не висит в воздухе: у каждой детали есть опора (кронштейн, стойка, подвес);
- случайность — только из зерна (`rnd`, `uniform`): сетка одна и та же при каждом запуске.

## Проверки
- `build.py` считает **незакрытые рёбра** (`export.open_edges`: у каждого направленного ребра должен быть
  встречный) и не пишет сетку, если они есть. У Исподи 0 на всех четырёх сетках.
- Два запуска `make parts` дают одинаковые sha256.
- Лист просмотра (`preview.py`) — до игры: кадр собирается за секунды, игра под lavapipe — за минуту.

## Бюджет
Секция здания 20–60 тыс. треугольников на LOD 0 (Исподь: бетон 52 тыс., коридор 25 тыс., зал 18 тыс., путь
52 тыс.), LOD и кластеры строит `meshpack` (`docs/mesh.md`).

## Чего нет
- Текстур-сканов (CC0): вопрос открыт у пользователя, он отменяет решение 2026-11-05 «без текстур». Фабрика от
  ответа не зависит: материалы — по имени.
- Расстановки по правилам (трубы вдоль любой стены сами): наполнение Исподи расставлено координатами.
- Запечённого затенения в вершинах (у фабрики `ao` = 1): его даёт поле расстояний.
