# Внутренняя документация Anathemyre

Что в игре есть, что каждая вещь значит и почему она такая. Пишется по ходу работы (правило пользователя
2026-10-29): **каждое изменение механики, контента, звука или анимации обновляет свой файл здесь в том же
коммите**. Числа баланса живут в коде, здесь — их смысл, связи и где их искать.

| Файл | О чём |
|---|---|
| [sound.md](sound.md) | звуки: какой что значит, когда звучит, почему такой; фон мира; расстояние; цена |
| [weapons.md](weapons.md) | оружие, классы, удары, качество, броня |
| [animations.md](animations.md) | передвижение, позы ожидания, оружие в руках и в ножнах, бой: состояние → поза |
| [people.md](people.md) | люди: тела, внешность, одежда и броня, бельё, причёски |
| [lights.md](lights.md) | свет ночью: факелы, фонари, прожекторы арены, свечение у огня |
| [time.md](time.md) | время мира: шаг 20 Гц, сглаживание между шагами, пауза и ускорение ×2, ×5 |
| [world-map.md](world-map.md) | карта мира 28×28 км: лагерь, долина, пустошь из зерна; рельеф кольцами вокруг камеры |
| [performance.md](performance.md) | устройство кадра, замер по участкам, найденные узкие места, что сделано и что дальше |

Как писать:
- По-русски, сухо и коротко. Таблица лучше абзаца.
- В начале файла — дата состояния и где код.
- Новая тема (фракции, экономика, ИИ, мир, интерфейс) — новый файл и строка в таблице выше.
- Картинки `stage0-*.png` — снимки этапа 0.
