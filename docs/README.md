# Внутренняя документация Anathemyre

Что в игре есть, что каждая вещь значит и почему она такая. Пишется по ходу работы (правило пользователя
2026-10-29): **каждое изменение механики, контента, звука или анимации обновляет свой файл здесь в том же
коммите**. Числа баланса живут в коде, здесь — их смысл, связи и где их искать.

Как писать:
- По-русски, сухо и коротко. Таблица лучше абзаца.
- В начале файла — дата состояния и где код.
- Новая тема (фракции, экономика, ИИ, мир, интерфейс) — новый файл и строка в таблице выше.
- Картинки `stage0-*.png` — снимки этапа 0.
