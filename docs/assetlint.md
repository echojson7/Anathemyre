# Линт ассетов (`tools/assetlint`)

Проверка готовых сеток `data/meshes/*.mesh` в CI (задача linux, после сверки сеток с генератором) — чеклист ассета
из разбора (`docs/assets_pipeline_review.md`, раздел 6). Рецепт может быть любым (`tools/parts`, `tools/weapons`,
`tools/meshgen.py`, Blender потом) — линт смотрит только на результат, поэтому ловит и то, что пересобрано вне CI
(сетки фабрики без bpy в CI не собираются).

    python3 tools/assetlint/assetlint.py               все сетки, правила tools/assetlint/rules.txt
    python3 tools/assetlint/assetlint.py data/meshes/vezha.mesh --verbose   одна сетка, с допущенными

Только Python 3 и numpy (в CI — `python3-numpy`, numpy 1.26; проверено и на 2.x). Все 65 сеток — около минуты.

## Проверки
Тело — связная по общим положениям часть сетки LOD 0 (вершины с разными нормалями в одной точке сварены).

| Проверка | Что | Порог |
|---|---|---|
| `open` | тело не замкнуто: у ребра нет встречного (число тел с дырой) | 0 |
| `tjunc` | Т-стык: вершина лежит внутри незакрытого ребра того же тела (трещина в свете и тенях) | 0 |
| `gap` | щель: два тела подходят ближе 5 мм, но нигде не касаются (ближе 0.2 мм) и не входят друг в друга (сторона по нормали ближайшего треугольника) — пара тел | 0 |
| `chord` | прогиб гладкой поверхности над ребром LOD 0 больше 0.5 мм (+10 % на оценку) | 0 |
| `chamfer` | фаска одним сегментом: плоская полоса ≤ 3 см шириной и ≥ 5 см длиной, на обоих длинных краях излом 35–65° к грани вчетверо больше полосы | 0 |
| `budget` | треугольников LOD 0 больше `budget` сетки; сетки без бюджета — тоже ошибка | — |
| `lod` | ошибка LOD N больше заданной в `budget` (Вежа: LOD 2 ≤ 5 см, `docs/vezha.md`) | — |
| тонкие стены | у сеток с коллайдером (здания) и замкнутых: наружная стена тоньше 0.5 м — **только предупреждение** со списком мест | — |

Как считается:
- **Хорда** — по нормалям вершин: кривизна вдоль ребра e с нормалями na, nb в концах κ ≈ |(nb − na)·e| / |e|²,
  прогиб дуги над хордой κ|e|²/8 (с поправкой 1/cos²(φ/4) — точно для круга, φ — угол между нормалями). Берутся
  два коротких ребра треугольника (длинное — диагональ, на двойной кривизне она складывает прогибы обоих
  направлений), рёбра с изломом нормали круче 61° (фаска со взвешенными нормалями) и рёбра от резкой кромки
  (нормаль в одном конце ровно поперёк ребра) не считаются. Так ловятся гранёные цилиндры, торы, своды и шланги
  с гладким бликом — и сглаживание через пологий излом профиля (оно тоже обещает глазу дугу, которой нет).
- **Щель** — сетка по клеткам 2 см, ближайшая точка треугольника (Эриксон). Касание в одной точке снимает пару:
  цилиндр, лежащий на плите, не щель, хотя у линии касания вершины в миллиметре от плиты. Поэтому щель
  стыка, где одна точка касается, а рядом зазор, не видна — это предел проверки.
- **Тонкие стены** — тело заполняется по клеткам 10 см (чётность пересечений по вертикали), снаружи — пустота,
  видная с края сетки вдоль оси, внутри — остальная пустота; стена — отрезок заполненных клеток вдоль оси между
  ними. Наружный карман, не видный ни вдоль одной оси, считается внутренним.

## Правила (`tools/assetlint/rules.txt`)
- `budget <шаблон> <треугольников> [lodN <ошибка м>]…` — бюджет; у каждой сетки он есть.
- `allow <шаблон> <проверка> <потолок> — причина` — нарушение допущено, но не больше потолка **на сетку**.
  Потолок — число нарушений на день записи: стало больше — снова ошибка, исключение не растёт молча. Исправил —
  опусти потолок или убери строку; строка без нарушений — тоже ошибка («лишнее исключение»).

Что допущено на 18.11 и почему — причины в самом файле. Коротко: люди, волосы и одежда — оболочки MakeHuman и
одежды (путь Б); Остов — плиты встык (переделка одним телом после цепочки света); машины — механические зазоры
между сотнями деталей; Исподь — зазоры наполнения и пологие изломы бетона под пределом фаски (вместе с пилотом
марша, PR 4); оружие — обмотки и кольца на рукояти без булевых операций.
