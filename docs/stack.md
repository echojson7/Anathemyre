# Стек

Решено 2026-11-05 разбором с чистого листа (документ «Anathemyre v2: стек с чистого листа»,
https://claude.ai/artifact/7Dd314G4SJ4LAZ7DX6UMnN). Старое правило «чистый C» снято.
**Основа** меняется только переписыванием, **заменимое** спрятано за нашим слоем.

## Основа

### Язык
- C++20 в сдержанном стиле: `-fno-exceptions -fno-rtti`, без виртуальных иерархий, без модулей C++20.
- В шаге мира нет STL-контейнеров, `<cmath>` и `std::sort`: свои контейнеры над аренами (`FixedArray` с
  `push_back`, пул с номерами-поколениями, `Span`, своя устойчивая сортировка). Причина — у libstdc++ и libc++
  разный порядок `unordered_map` и равных элементов после `std::sort`, а повтор должен совпадать на Windows и Linux.
- `std::pmr` разрешён вне шага мира: загрузка, инструменты, временные данные кадра. Сверху у арены всегда
  `std::pmr::null_memory_resource()`, чтобы конец арены не уходил молча в malloc.

### Компилятор
- clang одной закреплённой версии на обеих целях. Windows `.exe` — llvm-mingw (кросс-сборка из Linux/WSL),
  отладочная информация в PDB (`-gcodeview`, lld).
- gcc в CI вторым компилятором: только предупреждения и тесты, повтор проверяется на сборке clang.
- Флаги: всегда `-Wall -Wextra -Wpedantic -Wshadow` без предупреждений (в CI `-Werror`). Релиз `-O2`, отладка
  `-O0 -g3 -fsanitize=address,undefined` (Linux).
- Процессор: одна цель `-march=x86-64-v3` (AVX2) для всех сборок; `-march=native` запрещён.

### Графика
- Vulkan 1.3 напрямую: bindless через descriptor indexing (не descriptor buffer), buffer device address,
  timeline-семафоры, dynamic rendering, synchronization2. 1.4 не требуется, нужное из него — расширениями.
- VMA (выделение видеопамяти) и vk-bootstrap (instance, устройство, swapchain). Требуемые возможности
  устройства перечисляются явно, на неподходящей карте — понятная ошибка.

### Кадр и шейдинг
- GPU-driven: вся геометрия в общих буферах, экземпляры на GPU, отсечение и LOD в compute,
  `vkCmdDrawIndexedIndirectCount`. CPU пишет только изменившиеся экземпляры.
- `.mesh` сразу хранит кластеры по 64–128 треугольников (meshoptimizer); отсечение по Hi-Z прошлого кадра —
  позже, без смены формата.
- Список вызовов собирается упорядоченно (префиксная сумма) или ничьи глубины решаются по номеру экземпляра:
  иначе кадры в CI отличаются от запуска к запуску.
- Visibility buffer: первый проход пишет номер экземпляра и треугольника; свет считается в compute один раз на
  ячейку пиксельного правила и раздаётся на её пиксели кадра.

### Свет и туман
- Кластеры света + froxels в одной сетке: списки огней и объём тумана и пыли. Forward для частиц и прозрачного.
- Место под атлас теней огней с кешем (статичный огонь перерисовывает тень, только когда рядом движение).
- Алгоритмы света — пользователя (`light.glsl`), каркас их не навязывает.

### Люди
- Скиннинг compute-проходом в общий буфер положений, дальше люди идут как статика.
- Анимации из захвата, свой рантайм смешивания и IK (позы входят в шаг мира и повторяются бит в бит).
  Motion matching для ходьбы и бега — вариант, решается на этапе 3.

### Симуляция
- Фиксированный шаг 60 Гц рядом с игроком, дальний мир реже по уровням детализации. Постоянный поток
  симуляции + jobs.
- Детерминизм float (полный список запретов — `docs/invariants.md`): `-ffp-contract=off`, без `-ffast-math`,
  без `rsqrt`/`rcp`, свои sin/cos/pow/exp и шум, суммы по потокам в фиксированном порядке.

### Данные
- SoA, арены и пулы при старте, свои бинарные форматы (`.mesh`, `.skel`, `.anim`, `.tex`, `.font`, звук QOA)
  с загрузкой одним чтением. Свой текстовый формат описаний.
- Сохранения кусками «тег, версия, длина»: незнакомые куски пропускаются, недостающие поля достраиваются.
  Сумма сохранения — главная проверка повтора.

## Заменимое
| Что | Выбор |
|---|---|
| Окно, ввод, геймпад | SDL3 за `platform.h` (SDL_GPU не используем) |
| Звук | вывод через SDL3, микшер, реверберация и фильтры свои, звуки в QOA |
| Математика | своя на C++ с операторами, раскладка как std430 |
| Шейдеры | GLSL → SPIR-V (`glslangValidator`, `#include`), проверка `spirv-val`; горячая перезагрузка в отладке — внешний компилятор по изменению файла |
| Физика ragdoll | своя XPBD; перед этапом ragdoll день прототипа на Jolt для сравнения |
| Сборка | Makefile, unity build: игра, third_party, отладка, инструменты; `compile_commands.json` скриптом |
| Отладка | Tracy, Dear ImGui (только отладка), RenderDoc, Nsight Graphics, слои проверки Vulkan с проверкой синхронизации, свои замеры по этапам и GPU-таймеры; падения — минидамп на Windows, стек на Linux |
| Ассеты | glTF из Blender → наши форматы (cgltf в `tools/`), meshoptimizer: LOD, кластеры, сжатие вершин; захват (BVH, FBX Mixamo) через Blender в glTF |
| CI | GitHub Actions: Linux + lavapipe с закреплённой версией Mesa, кадры с допуском; Windows-exe под Wine для повтора |

## Сторонние библиотеки в рантайме
Только если выполнены все 5 условий (правило пользователя 2026-10-30, третье условие изменено 2026-11-05):
1) решает задачу заметно лучше нас и задача уже на очереди; 2) лицензия MIT/zlib/BSD/Apache-2.0/CC0, без GPL/LGPL;
3) C или C++, исходники в `third_party/` с версией, собираются нашим Makefile без исключений и RTTI в нашем коде;
4) не участвует в шаге мира (детерминизм от неё не зависит); 5) спрятана за нашим тонким слоем.
Каждую согласует пользователь, запись — в `docs/decisions.md`. Согласованы: SDL3, VMA, vk-bootstrap, QOA;
в отладке — Tracy, Dear ImGui. Без игровых движков.

## Ассеты людей и движения
- Люди: MakeHuman (CC0), конвертер из склада (`tools/humanconv`, 5 LOD, морфы), скелет MakeHuman `game_engine`
  (около 50 костей) под захват движения. Окончательный выбор скелета — по итогу этапа 2.
- Захват движения: CMU Motion Capture Database (BVH; можно в коммерческой игре, нельзя перепродавать данные) —
  ходьба, бег; Mixamo (скачивает пользователь, в игре только внутри наших `.anim`) — удары, блоки, уклоны,
  реакции. Платные паки — решает пользователь. Ретаргет офлайн в Blender, затем свой конвертер в `.anim` с метками.
- Шрифт интерфейса: IBM Plex Sans (SIL OFL), конвертер `tools/fontconv` из склада.

## Инструменты разработки
- git + GitHub (`echojson7/Anathemyre`), ветка v2 — `claude/project-thread-vwjaxp`.
- Python 3 + numpy для конвертеров, Blender 4.x для ретаргета, Xvfb + lavapipe для кадров без окна.
- `tools/run.sh`: `git pull`, сборка, запуск. Пользователь запускает только его.
