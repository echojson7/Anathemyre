Запрос 2026-10-29 (раунд 1, PR #36 влит): бег, подъём, падение, увороты, позы, мобы, хват, ножны, бой телом.

Разделение с веткой людей (MakeHuman):
- люди: суставы в src/sim/body.c, скиннинг, морфы, броня, сокеты;
- анимации: character_pose в src/game/anim.c, походка, хват, оружие на слоте CHAR_BONE_WEAPON (20);
- суставы брать только из g_body_bones/g_body_sockets.

Раунд 2 (2026-10-29, PR #42 влит в stage0/test-room 13:46). Замечания пользователя:
- бег/ходьба «до ума», инерцию старта и остановки НЕ трогать — она нравится;
- позы покоя были «слишком как в Kenshi»: оставлены только корточки (переделаны). Покой разделён: часто — обычные движения стоя (вес, взгляд, шея, лямка, лоб, рукоять, ладони), редко — позы (корточки, сидит, руки в колени, смотрит вверх), только у стоящих дольше 4 с (CharPose.idle);
- оружие за спиной должно прилегать к спине;
- бой: держали слишком близко, удар визуально не доходил, часть тела считалась случайно.

Решение по бою (раунд 2):
- сим: при замахе бросается точка удара на цели (CombatWorld.aim_x/aim_y/aim_s); часть тела — что первым пересечёт след удара по капсулам стойки g_body_hit_guard с учётом разворота цели. Лежачих бьют куда придётся;
- вид: оружие ведётся рамкой (стойка/блок по классу, удар через ту же точку), правая рука IK; уворот — удар в место, где цель была; блок — клинок встаёт перед целью;
- дистанция: стоят на 0.82–0.98 досягаемости; ENGAGE_R в field.c 3.5.

Правило пользователя 2026-10-29: каждое изменение анимаций/оружия/механик обновляет docs/ (animations.md, weapons.md) в том же коммите. Журнал боя чистить combat_events_done(w), не ev_count = 0 (звук).
