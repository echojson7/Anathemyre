Сделано (PR #45 в stage0/test-room, ветка claude/project-thread-4xfiuf):
- DAY_LENGTH_S 240 (main.c); луна в sky.c вдвое слабее; Sky.night 0..1 — по нему зажигают огонь.
- PointLight во FrameView, рендер берёт ≤16 ближайших видимых (UBO binding 0, common.glsl). Свет без теней в scene.frag, свечение пыли в atmos.frag (интеграл 1/d²). Днём источников 0 — цена нулевая; ночью на llvmpipe сцена +29 %, атмосфера +20 %.
- Арена: 2 прожектора конусом + 2 лампы на воротах (arena_view_lights).
- Факел: слот кости CHAR_BONE_TORCH, CharPose.torch (поднять), torch_build в weapon.c. Носят: часть бродящих, 2 из шайки, 3 зрителя, сторожа и каждый 5-й прохожий Скудели.
- Зрители арены = Crowd (crowd_init_still) на поле; жители Скудели тоже на поле (листы, роли в CharSheet.role). Имена — src/game/names.c.
- --look-slot N — осмотр чужого для снимков. Кадры: /mnt/project-files/anathemyre/shots/night/.
