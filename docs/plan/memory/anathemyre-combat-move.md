Это правило для всех тредов анимаций.

Итог (Claude Doc https://claude.ai/artifact/CsSvdZUT9UccZyD3KJ3czN):
- Стопы в стойке не шагают: apply_fight в src/game/anim.c при guard=1 заменяет цели стоп походки на неподвижную стойку; опорная стопа едет 101–106% пути (ходьба 4–6%). READY двигается 1.1–1.4 м/с, разворот тоже без переступания. Отброс при сбивании — скольжение 0.5–1.2 м за 0.3 с.
- Тела: враги почти не пересекаются (дистанция 0.82–0.98 досягаемости), свои до 1% кадров >3 см; стоящие топчут лежащих 3.5–5.7% кадров (расталкивание r=0.6 м по точке). Оружие сквозь тела — тема рук.
- Темп: проводка удара 0.15 с у всех (балке надо 0.25–0.35), подъём 1.08–1.44 с при падении 0.8 (надо ~2.0), уворот стартует с началом чужого замаха и висит.
