Разбор ИИ боя (основа v4): https://claude.ai/artifact/QhocBh1xDzbV8CJ7Em5TAB. Гомеостат — [[anathemyre-world-director]].

Основа (v3, остаётся):
- Вся карта 28×28 км в памяти (сетка 16 м ~12 МБ + дюны в точке), clipmap. Подробно ~200 м у своих и ~400 м у точки взгляда камеры, поводок 1 км.
- Люди в отрядах числом, личность у заметных, тела рядом. Вдали отряды-точки на графе мест, цикл раз в секунду.
- Главный поток + пул; поток симуляции, когда шаг боя > ~2 мс. Шаг пишет мир, кадр только читает.

Решения пользователя v4 (2026-10-30, не переспрашивать):
- ИИ: utility на всех слоях + HTN-лайт (фракции, отряды вне боя) + тактический слой боя (тактическая карта, командир с манёврами, места и роли). GOAP в бою нет. LOD ИИ по ситуации бойца, не по камере.
- Манёвры как приказы игроку — нет. Стрелковое оружие будет (укрытия в тактической карте).
- Моды будут: свой текстовый формат описаний, до фракций и экономики; встроенный контент в тех же файлах; без JSON/TOML.
- Сохранения как проще: короткая пауза; фон потом.
- Путь: на отряд, поле направлений на общую цель, цена дорог + Дейкстра; без ORCA; пулы путей/полей, очередь с бюджетом, пересчёт только по событию («чтобы пути не создавались бесконечно»).
- Звук битвы: без гула сечи и виртуализации.
- Сложности нет: один лучший характер Гомеостата. Vulkan/macOS/Wayland — пока забыть.

Этапы: 1–4 влиты (PR #60, #62, #65, #67; отряды — docs/bands.md). Этап 5 журнал и сохранения — PR #75 влит 2026-10-30 (docs/save.md, проверка tools/save_check.sh). Этап 6 описания в файлах — PR #94 влит 2026-10-30, см. [[anathemyre-defs-stage]]. Порядок v5 (сверка 2026-10-30): тактика боя → стрелковое (предложение, пользователь не ответил) → путь → заготовки локаций → распорядок → один реестр людей + команды отдельно от фракций → фракции+экономика+караваны → Гомеостат. Параллельно: тред архитектуры (скелет, клипы), свет, Vulkan; этапы мира они не задевают. Мир не наполнять без пользователя.

**How to apply:** этапы идут по плану без отдельного «да» на старт, мерж — по «да». Не возвращать убранное без замера или новой причины. См. [[anathemyre-perf-cpu]].
