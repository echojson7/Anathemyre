Запрос 2026-10-29: рядом с тестовой сценой локация в несколько этажей, торговцы, улицы с прилавками, мелочи; «не очень большой, главное чтобы не казался пустым» и «объекты не как ctrl+c ctrl+v». Отдельных концепт-артов у пользователя в репо и файлах проекта не нашлось — опора на «Атмосферу» из CLAUDE.md.

Сделано (влито в stage0/test-room, PR #39): src/game/town.c/.h. Посёлок x 56..100, z -22..26, три яруса (0 / 3.5 / 7 м, пандус и лестница, town_ground), за ним древняя стена 30–38 м с проёмом и зелёными знаками, мачта с красным огнём. 22 дома, 20 прилавков 6 видов, всё процедурно со своим rng-потоком (seed, поток 7). Жители: торговцы, сторожа, зеваки, 20 прохожих по графу узлов. Дальние жители обновляют позу 60–120 Гц (иначе +0.14 мс CPU на кадр). Сетка посёлка 35.5 тыс. треугольников, отдельный GpuMesh.

Открыто: механики торговли нет (торговцы только стоят); второй, «зелёный» уровень с переходом через меню делает другой тред.
