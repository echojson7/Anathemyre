Запрос пользователя 2026-10-29: управлять своими и атаковать цели «как в Kenshi». Пользователь ушёл спать и велел делать без ожидания «да», вопросы — в конце.

Устройство (тред «Добавить приказ атаковать цель», ветка claude/project-thread-asuttg → PR в stage0/test-room):
- Один CombatWorld на весь открытый мир (Field, FIELD_MAX 1024). У каждого тела постоянный слот; вне боя слот спит (combat.idle), телом правит Player; враг рядом — просыпается, бой ведёт combat_tick. Player.ctrl: FREE / CHASE / FIGHT, Player.slot.
- combat: idle[], order[] (цель по приказу), foe[] — вражда команд. Арена и бенчмарки не изменились (суммы те же).
- Команды: отряд 0 (FF_PLAYER|FF_ASSIST), мобы треда анимаций 1 (FF_ASSIST), бродящие 2+i (без флагов, только отбиваются). Вражда забывается через 40 с без боя.
- Управление: ПКМ по чужому — выбранные бегут и бьют его, пока не выбыл; ПКМ по земле — уйти (из боя при первой возможности); H — стоп (бросить приказ, но отбиваться). Красное кольцо под целью. S занят камерой.
- Проверка без окна: --field-bench N (сценка + нагрузка на N тел; 1000 тел ≈0.5 мс/кадр). Снимки: --attack K (отряд сразу атакует бродящего K).
- Вид боя на поле — fight_anim треда анимаций (он владеет видом боя, может править ENGAGE_R в field.c). Влито в stage0/test-room (PR #38) 2026-10-29.

**How to apply:** новые NPC ставить на поле через field_add; в своих update не трогать тело при p->ctrl != CTRL_FREE. См. [[anathemyre-anim]], [[anathemyre-movement]], [[anathemyre-hud]].
