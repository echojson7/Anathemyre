Claude Doc «Anathemyre: разбор стека и реалистичного освещения» (2026-10-30): https://claude.ai/artifact/RDDuXB7cWxKTpHKaNfoLGN. Описание всех частей — docs/lighting.md.

Решения пользователя: аппаратных лучей RTX не будет никогда (2026-10-30 06:15), остаёмся на C. Каждый способ — рабочий переключаемый вариант от лёгкого к тяжёлому, не проба. Автоэкспозиция и свечение — только слабыми и выключенными по умолчанию (пользователь убирал их 2026-10-29, [[anathemyre-visual]]).

Этапы (все в одной ветке claude/project-thread-fg8d0l, PR в stage0/test-room):
- 1 GGX, кривые, экспозиция, bloom, наборы ПРЕЖНИЙ/БЫСТРЫЙ/РЕАЛИСТИЧНЫЙ — PR #77 влит.
- 2 НЕБО ПО СЕТКЕ — PR #87 влит.
- 3а каскады ±180/±700, мягкий край, контактные (привязки 32–35; РЕАЛИСТИЧНЫЙ на PBR Neutral, AgX блёклая) — PR #92 влит.
- 3б GTAO (пункт УГЛЫ, 36–37) — PR #95 влит.
- 4 ЗОНДЫ (DDGI: клетки 1 м VOXEL_PASS, 8192 зонда через 4 м, 1/8 за кадр, Чебышёв; 38–41, PS_VOXEL) — PR #98 влит 2026-10-31 11:03.
- 5а ТЕНИ ОГНЕЙ (кубы 256² для 4 ближних огней r ≥ 2 м, новый целиком, дальше грань за кадр; PS_TORCH без depth clamp, near 0.3 м, иначе рука и колпак закрывают всё; 42–43; RB_SHADER_FILES 8; --light-parts 10 чисел) — PR #104 влит 2026-10-31 11:41.
- 5б свет с экрана (SSGI) поверх зондов — дальше.

Правила для новой части света:
- рецепт SPIR-V в tools/spv/list.txt + ./tools/spv/build.sh, устаревшие рецепты убрать руками; in/out с layout(location); на конвейер Vulkan ≤ 32 объявленных привязок;
- проверка: ПРЕЖНИЙ и БЫСТРЫЙ бит в бит с базой (отличаются только строки 11–17 HUD к/с);
- столбец прохода в docs/performance-stages.md;
- вписать в stage_render (controls.c, ЗАМЕР ПО ЭТАПАМ): тени — с ТЕНЯМИ, AO — с AO, остальное — с этапом 8 СВЕТ (PR #103 треда производительности, 2026-10-31). light_torch вписать, когда #103 влит.

**Why:** пользователь хочет картинку «как UE5/RTX» без RTX и честное сравнение цены каждой части.
**How to apply:** короткие этапы, после каждого — ночные/дневные кадры «было/стало» (пикселизация выключена, время стоит), PR и «да» пользователя. См. [[anathemyre-perf-stages]], [[anathemyre-visual]].
