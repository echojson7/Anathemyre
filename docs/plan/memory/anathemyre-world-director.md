Гомеостат:
- регулятор мира, не рассказчик для игрока;
- сводка мира из журнала;
- «прилив» целей по процессу Орнштейна — Уленбека (волны в игровые месяцы);
- коридор с мёртвой зоной;
- рычаги только из мира (буря, засуха, находка руин, пробуждение машин, беженцы, миграции, мор, раскол, караван из-за края), у каждого условия, сила, перезарядка, предвестники; у крупных долгая перезарядка (v3: без бюджета влияния).
Правила честности:
- ничего не создаётся рядом с якорями;
- не целится в игрока;
- передышка после беды (как AI Director в L4D);
- предвестники перед крупным;
- полного вымирания нет (расколы, беженцы);
- всё в журнал с причиной.
Сложность = характер мира (ширина коридора, размах прилива, длина перезарядок). Раз в игровой час, ≤1 мс частями.

Контракт новой механики: таблицы, ближняя и дальняя версии системы, события, рычаг, бюджет, файл docs.

Бюджеты (мин. железо, запас под ускорение времени ×5): CPU кадра ≤0.25 мс в тестовой сцене и ≤1 мс в мире; тик рядом 1000 воинов ≤3 мс на 4 потоках; дальний мир 4 тыс. отрядов ≤0.2 мс/тик; создание мира ≤10 с; 1 игровой год в бенчмарке ≤10 с; ОЗУ ≤2 ГБ, видеопамять ≤3 ГБ.
Не нужно: ECS, физдвижок, скрипты/VM, волокна, double, гексы, воксели, нейросети, GOAP, симуляция на GPU, mesh shaders/RT, сеть сейчас.

**Why:** чтобы следующие треды предлагали механики через контракт и не возвращали отвергнутое без новой причины.
**How to apply:** кода нет до «да» пользователя; новые идеи проверять по принципам и бюджетам. Пока идёт работа над движком, не выносить на решение лор и контент, только механизмы.
