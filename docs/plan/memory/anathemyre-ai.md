Суть схемы:
- ИИ: utility на всех слоях, HTN-лайт (готовые способы из таблиц C, без поиска с откатом) для фракций и отрядов вне боя — заменяет прежнее «автомат на задачу». Новый тактический слой боя: тактическая карта (клетки 2–4 м на бой), командир отряда с манёврами (держать линию, натиск, охват, сосредоточить, сомкнуться, отход, бегство), места и роли бойцам. Боец — utility с кривыми + мгновенные реакции. GOAP в бою отвергнут (исход зависел бы от камеры, 20 из 1000, в ближнем бою нет цепочек); возможен позже для редких задач заметных NPC вне боя.
- LOD ИИ по ситуации бойца, а не по камере: схватка 4 Гц, вторая линия 1 Гц; камера влияет только на позы. Сейчас COMBAT_THINK_TICKS 5 (все раз в 0.25 с).
- Путь: путь на отряд, поле направлений на общую цель, цена дорог + Дейкстра по графу при блокировке; ORCA не сейчас.
- Звук: предлагал приоритеты и «гул сечи» — пользователь ОТКАЗАЛ; остаётся «вытесняется самый тихий».
- Сохранения: решено проще — запись с паузой (этап 5 ведёт тред плана); фон и своё сжатие позже (LZ4 нельзя).
- Моды: решено — свой текстовый формат описаний до фракций и экономики.
