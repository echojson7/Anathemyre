Пользователь отказался от ограничителя FPS (PR #4 закрыт): нужен только vsync вкл/выкл на F3, без предела кадров.
Падение 4000 → 2450 к/с (0.25 → 0.41 мс) объяснено ростом геометрии: персонаж 4 072 → 8 748 треугольников, фигур 9 → ~35, всё рисуется в тени и в сцене. Сутки, фильтр и HUD почти бесплатны. FPS сравнивать только при одинаковом зуме (разрешение зависит от камеры/пикселя).
Оптимизации (2026-10-29): пользователь хочет только проверенные и важные подходы, «не натягивать сову на глобус», реализовать качественно, чтобы потом не мешало. Предложены три стандартных: отсечение по пирамиде видимости, LOD фигур, инстансинг (кости одним буфером).
