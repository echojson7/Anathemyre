Пользователь 2026-10-30 13:03: во всех анимациях учитывать скорость, с которой они идут. Между анимациями она не должна сильно отличаться, только в рамках реализма. Пример: падение не должно быть очень быстрым по сравнению с подъёмом.

**Why:** нереальный темп одного клипа рядом с другими выдаёт игру сильнее, чем неточная поза.

**How to apply:** при любой новой или правленой анимации сверять её длительность с живым человеком и с соседними клипами (падение/подъём, замах/удар, доставание, шаг). См. [[anathemyre-anim]], [[anathemyre-gait-review]].
