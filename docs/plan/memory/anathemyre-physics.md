Пользователь 2026-10-30 17:23: «нужна ragdoll-система и физика как в Kenshi и Skyrim»; вдали и после ухода объекты застывают; расставленные над землёй вещи падают, когда приходит игрок, а вдали висят в одной точке; физика только в видимой области.

План (Claude Doc https://claude.ai/artifact/JNqktCXy7dUeQesjwwArr2): свой XPBD в src/sim/phys.c (PhysX/Jolt нельзя: C++ и шаг мира), состояния «считается / спит / застыло», зона — круг 150 м вокруг своих и точки камеры с гистерезисом 20 м, режимы расстановки «осесть / висеть / намертво» (как флаг Don't Havok Settle в Skyrim) + кнопка ОСАДИТЬ в редакторе, ragdoll из 11 частей на капсулах скелета, переход клип→ragdoll с «мышцами», перенос на мягкой пружине без столкновения с несущим, бюджет 48 ragdoll / 256 вещей, детерминизм (-ffp-contract=off, свои sin/cos). Этапы 1–7: ядро → вещи на земле → здания → ragdoll мёртвых → сбитые → перенос → удары толкают.
