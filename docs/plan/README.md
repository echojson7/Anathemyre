## Как работать (правила пользователя)
- Отвечать по-русски. Сначала короткий план и «да» пользователя, потом код. Короткие этапы, каждый собран и проверен.
- PR только в `stage0/test-room`, не в `main`. Влитие — по «да» пользователя.
- Пользователь запускает только `cd ~/anathemyre-dev && git pull && ./tools/run.sh --novsync`. Других команд ему не давать.
- Замеров и скриншотов у пользователя не просить, мерить самим (`--bench`, см. docs/performance.md). Без лишних действий и тестов: CI проверяет сборку.
- Свет и шейдеры пользователь переделывает сам: не трогать и не подстраиваться.
- Каждое изменение механики обновляет свой файл в `docs/` в том же коммите.
- Шаги одного потока идут строго по очереди; границы файлов задаёт промпт шага; SAVE_VERSION поднимает тот, кто вливается; перед PR подмешать свежую test-room и дождаться зелёного CI; не больше 3 открытых PR.
