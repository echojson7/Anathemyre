## Что сделать
Материал (вид `material` в data/defs/materials.txt, появился в #105) становится единственным местом, где записано, из чего сделана вещь и как она звучит.

1. **Звук удара у материала.** Новый ключ, например `impact metal|wood|concrete|cloth|leather|flesh|glass` (точный список предложи сам, без лишних классов). У каждого из 37 нынешних материалов он есть, у дочерних берётся через parent. Вид (view/sfx.c) разрешает класс в SFX по таблице «класс → звук». Недостающие звуки (стук дерева, бетона, глухой шлепок ткани) синтезировать в src/audio/ по правилам docs/sound.md: индустриально и сухо, без «мультяшных» звуков.
2. **Звук падения физических вещей по материалу.** Лом, выроненное оружие и вещи на земле при ударе о землю или друг о друга звучат по своему материалу. Громкость зависит от скорости удара, слишком тихие удары не звучат, есть предел на число звуков за кадр. Сейчас там SFX_DROP_METAL и рассыпанные числа. Если в phys нет события «касание со скоростью», добавить его: phys пишет события в мир, звук их только читает. Сим не включает view.
3. **Одно трение и один отскок на весь мир.** Убрать PhysDesc.friction и PhysDesc.bounce (sim/phys.h, scrap.c, ground.c), вместо них две константы физики. Материалу физика не нужна, это решение пользователя.
4. **Чего нет и не будет:** износа у материала, шероховатости, металла и любых параметров света (свет пользователь переделывает сам). Шаги остаются по типу земли, как сейчас (view/sfx.c, step_sound), их не трогать.

## Проверка
- Сборки релиз, отладка (ASan/UBSan) и Windows (mingw) без предупреждений; tools/layers.sh чистый.
- Кадры бит в бит на Vulkan (lavapipe, без пикселизации, время одно и остановлено).
- Сумма мира, сохранение (save_check.sh), описания и моды (defs_check.sh) и бой бит в бит. Исключение — сцены с физикой вещей: трение и отскок поменялись, там сдвиг ожидаем. Покажи его один раз и объясни.
- defs_check.sh дополнить двумя случаями: мод меняет impact у материала; неизвестный класс impact даёт ошибку «ОПИСАНИЯ: файл:строка».
- Звук: сценка в WAV без устройства (как в CI) с падением лома на бетон и песок, и удар по железу.
