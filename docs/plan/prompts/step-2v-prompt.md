# Шаг 2в мастер-плана: вещи (промпт для рабочего треда)

Ты ведёшь шаг 2в, поток 2 этапа В. Цель — вещь описана одной записью item и живёт в одном месте с одним переходом item_move.

## Что сделать (1–2 PR)
1. **Одна запись item с компонентами.** Вместо видов weapon/armor/goods — `item` с общими полями (имя, размер в клетках, вес, стопка, материал по умолчанию по имени, вид на теле и на земле, hides) и вложенными компонентами weapon / armor / wear / container / light / phys (как ThingComps у RimWorld). data/defs/*.txt переписываются один раз, parent и моды работают как раньше.
2. **GEAR_* и g_gear_file — в описания:** `look jacket` — имя сетки, вид разрешает его сам. Item.id u8 больше не предел.
3. **Материал вместо особых полей:** ArmorDef.metal и WeaponDef.voice/WeaponVoice уходят, звук удара и блока — по паре материалов (оружие × броня или клинок) через mat_impact() из #111. Временную body_mat в view/sfx.c заменить материалом вещи. Голос удара оружия, если нужен отдельно от материала, — строковое имя звука в компоненте weapon, разрешает вид.
4. **ItemStack 8 байт:** def u16, материал u8, качество u8, число u8, зерно u16 (без износа: решение пользователя). Под качество и приставки место есть, наполнение — после шага 4.
5. **Одно поле места + item_move(from, to)** в sim/items.c: ЗЕМЛЯ (Ground + тело phys в зоне), РУКА, ТЕЛО (слот), СУМКА (сетка 9×6), СТОЙКА/ЯЩИК (объект с container — только место под него, объекты делает 2б). item_move создаёт и гасит физическое тело и пишет событие в журнал. Inventory, CharSheet.equip, Ground, CombatWorld.gitem и Squad.pick переходят на номера вещи и item_move вместо своей логики.
6. **Факел** — вещь с компонентом light. Если 2б уже влил функцию сбора огней, подключи факел к ней; если нет — оставь torch_light как есть и напиши в мастер-тред.
7. SAVE_VERSION +1, сохранение пишет имена описаний (DefMap) как сейчас.

- Можно: data/defs/weapons.txt, armor.txt, goods.txt (или новый items.txt вместо них); виды item в src/defs/; sim/items.{c,h}, sim/inventory, sim/ground, sim/loot, squad (только подбор), CharSheet.equip; в sim/combat.c — только строки gitem/подбора/выпадения оружия; view/loot_view, view/sfx.c (звук попадания и body_mat), hud (инвентарь), look (GEAR → имя сетки), content/weapon.c (только чтение формы из item); io/save; docs (items/weapons/content/materials).
- Нельзя: object/prefab, content/ локаций, сбор огней (2б); балансовые числа и длительности в combat.c, combat.txt, anim, body, fight_anim (2е/2г); debug/; шейдеры и свет.
