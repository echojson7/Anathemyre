## Четыре PR по очереди
Следующий PR начинается после того, как предыдущий влит. Перед каждым PR — короткий план и «да» пользователя. Влитие тоже по его «да».

### PR 1. Vulkan по умолчанию
- Бэкенд по умолчанию — Vulkan, GL пока остаётся страховкой: Vulkan при сбое уходит на GL с СБОЕМ в журнале, как сейчас.
- Пользователь запускает только `cd ~/anathemyre-dev && git pull && ./tools/run.sh --novsync`. Это Windows-exe из WSL, RTX 5070. Никаких отдельных команд ему не давать.
- Попросить у него три вещи: картинка на Vulkan в порядке (строка «РЕНДЕР СЕЙЧАС»); таблица ЗАМЕР ПО ЭТАПАМ; одно сравнение VRS вкл/выкл. Для сравнения на один запуск нужен GL. Придумай, как переключить его из меню, чтобы не давать отдельной команды, например через пункт РЕНДЕР и перезапуск.
- Готово: Vulkan стартует у пользователя без СБОЯ, цифры VRS получены.

### PR 2. Удалить GL и переключатели-сравнения
- Удалить rb_gl.c, gl.c, контексты WGL/GLX в platform_*.c, пункт меню РЕНДЕР, ключ --gl, ветки «если GL» в render.c.
- Удалить переключатели-сравнения, у которых решение уже принято: --hash-noise (остаётся 3D-шум), --ao-half, --no-mdi, --no-skin-cache, режимы u_skinned 1/4/5 (остаётся один путь). Вместе с ними уходят их пункты меню и столбцы.
- VRS: если по замеру пользователя выигрыш меньше 3 %, вырезать совсем. Иначе перенести на Vulkan (сейчас там g_vk.caps.vrs = false).
- CI: все шаги с кадрами (LIBGL_ALWAYS_SOFTWARE) перевести на lavapipe (VK_ICD_FILENAMES), сохранить ASan, проверку сохранений, описаний, боя и отрядов. Эталон кадров теперь Vulkan.
- Скриншоты в контейнере: xvfb + lavapipe, пикселизация выключена, время суток одно и остановлено.
- Обновить docs/vulkan.md, docs/render-backend.md, docs/performance-stages.md и память anathemyre-vulkan.
- Готово: GL нет ни в коде, ни в меню, ни в CI; мир и бенчи бит в бит; кадры на Vulkan такие же, как в PR 1; у пользователя всё работает обычной командой.

### PR 3. Папки по слоям, бит в бит
- Раскладка из раздела 2 разбора: core/ → defs/ → мир (sim/, ai/, world/, io/) → content/ → view/ → app/. render/, audio/ и platform/ — боковые слои, мира они не видят. game/ раскладывается по этим слоям, main.c, controls и bench уходят в app/.
- defs.c без include render/audio/game: имена сеток и звуков хранятся строками, вид разрешает их сам.
- World без GpuMesh: постройки зала берут своё зерно, чтобы не сдвинуть людей. Нужен явный ключ сортировки корзин вместо адреса GpuMesh (подвох в памяти anathemyre-perf-cpu).
- Скрипт проверки #include по таблице слоёв, в CI.
- Убрать устаревшие комментарии (№13 разбора).
- Готово: мир, сохранения, бенчи и кадры бит в бит; CI ловит запрещённый include; docs/code.md описывает слои.

### PR 4. Модуль debug/
- debug/ — отдельный модуль на уровне app/, игра без него собирается и работает. Туда уходят арена (в игре её не будет), Мерильня, стенд людей, редактор внешности, кнопки лома, вещей и пробных отрядов.
- Отладочные просьбы, которые сейчас живут флагами в World (phys_drop, loot_drop, пробные отряды), заменяются одной очередью отладочных команд в debug/.
- Пять бенчей (--arena-bench, --battle-bench, --battle-verify, --field-bench, --move-bench) становятся одним --bench со сценариями из файла. Суммы и цифры каждого сценария совпадают с прежними.
- Меню НАСТРОЙКИ остаётся, его отладочная часть идёт из debug/.
- Готово: в World нет отладочных полей; один --bench даёт прежние суммы; CI зелёный; docs обновлены.
