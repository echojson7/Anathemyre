# Шаг 2е мастер-плана: числа боя в combat.txt (промпт для рабочего треда)

Ты ведёшь шаг 2е, поток 3 этапа В. После него этот же поток делает 2г (скелет, .anim, наборы действий), промпт на 2г пришлёт мастер-тред.

## Что сделать (1 PR, бит в бит)
1. Все балансовые числа боя из sim/combat.c (и ai/fighter.c, если там есть такие же) переезжают в data/defs/combat.txt: пороги и множители морали (например, мораль < 40 → ×1.6), кровотечение, высота прицела aim_y, шансы ±0.1/0.15, скорость поворота, радиусы и прочее, что игрок или мод захочет крутить. Опись — пункт №10 разбора.
2. Форма записи — по образцу нынешних attack/quality: один блок, например `tuning combat`, ключи английские, комментарии — что значит каждое число. Мод правит любое число; неизвестный ключ — ошибка «ОПИСАНИЯ: файл:строка».
3. Длительности состояний (FS_KNOCKED, GETUP и т. п.) НЕ трогать: они переедут в наборы действий в 2г.
4. Числа читаются в одну структуру при загрузке, бой берёт их оттуда; в горячем цикле никакого поиска по имени.
5. Числа разбирать своим разборщиком (мантисса/10^n), как уже сделано, чтобы бой остался бит в бит.
