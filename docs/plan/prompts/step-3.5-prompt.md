## Что сделать
1. Сейчас расталкивание — круги 0.6 м (`separate_job` в combat.c) и обход лежащих отрезком (`around_bodies`). Заменить на одну систему: стоящий — вертикальная капсула (радиус и рост из `g_body`), масса из тела и снаряжения. Разрешение пересечений капсула-капсула мягкое (позиционная поправка по массам за шаг, без скоростей), через хеш-сетку (`grid_*`), без «все со всеми».
2. Стоящий и ragdoll: живые толкают ragdoll (капсулы ragdoll получают импульс в XPBD, лёгкий), ragdoll мешает идущему (идущий обходит или перешагивает — не застревает). Запечённое лежащее тело (уснувший ragdoll) — набор неподвижных капсул для ходьбы, но будится при сильном толчке (порог в combat.txt или physics).
3. Удар толкает: сильный удар даёт капсуле цели сдвиг (вместо нынешнего отброса числом), строй проседает.
4. Стены и постройки — как у ходьбы, коробки физики объектов (шаг 2б).
5. Параллельно по ячейкам сетки с детерминированным порядком (двухфазно: собрать поправки, затем применить по номеру), чтобы 1/2/4/8 потоков давали одно.
6. Убрать старые круги и отрезки, вместе с их числами.
