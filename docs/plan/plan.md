**Правила, чтобы ничего не сломать:**

1. У каждого потока в промпте записана граница файлов: что он правит и что ему трогать нельзя. Общие файлы (таблица видов в defs.c, Makefile, SAVE\_VERSION, docs/README.md) правятся только дописыванием строк. Версию сохранения поднимает тот PR, который вливается, сразу после подмешивания свежей test-room.

## Правила для всех шагов

- Работа идёт потоками (раздел «Параллельные потоки» ниже). Внутри потока шаги идут строго по очереди, а потоки между собой не пересекаются по файлам. Пункт закрыт, когда он влит и проверен у тебя (`git pull && ./tools/run.sh --novsync`).
- Каждый шаг: план → «да» → PR в stage0/test-room → «да» на влитие. Промпт в рабочий тред пишет мастер-тред.
- Общие для всех шагов проверки: сборки релиз, отладка (ASan/UBSan), Windows без предупреждений; бит в бит там, где шаг не должен менять картинку или мир; столбец в ЗАМЕР ПО ЭТАПАМ для любого нового прохода; документация в docs/.
- Вещи, которые нужны следующему шагу, закладываются в предыдущем (например, параметры материала для света), а не латаются потом.

## Шаг 2. Архитектура

**2.0 Слои и чистка.** Один тред, четыре PR по очереди, каждый влит до начала следующего:

1. Vulkan по умолчанию. GL пока остаётся страховкой. Ты один раз запускаешь обычной командой и проверяешь картинку, а также делаешь один замер VRS вкл/выкл на GL.
2. Удалить GL целиком (rb\_gl.c, gl.c, WGL/GLX, пункт меню) и переключатели-сравнения (--hash-noise, --ao-half, --no-mdi, --no-skin-cache, режимы u\_skinned 1/4/5). VRS: если по замеру даёт меньше 3 %, вырезать, иначе перенести на Vulkan. Кадры CI и эталоны переходят на Vulkan (lavapipe).
3. Папки по слоям: game/ → sim/, content/, view/, app/; defs без render/audio/game; World без GpuMesh; проверка #include в CI. Мир, сохранения и кадры бит в бит.
4. Модуль debug/: арена, Мерильня, стенд людей, редактор внешности, кнопки лома, вещей и пробных отрядов (одна очередь отладочных команд вместо флагов в World), пять бенчей станут одним --bench со сценариями.

**2а Материалы поверх #105.** Материал несёт вид и звук удара вместо ArmorDef.metal и WeaponDef.voice. Трение одно на весь мир, PhysDesc.friction уходит. Износа нет. Звук шагов зависит от типа земли, а не от материала.

**2б Объекты, заготовки, чанки.** Виды object и prefab в defs, экземпляры SoA по чанкам в world/. Свет — компонент объекта: один сбор огней вместо \*\_lights(). Коробки статики берутся из описания, поэтому лом больше не проваливается и этап 3.7 отменён. Стена, дверь и перекрытие — отдельные экземпляры под будущее строительство. Отличия от заготовок не сохраняются. Первой переезжает Скудель.

**2в Вещи.** Одна запись item с компонентами weapon/armor/wear/container/light/phys, GEAR\_\* переезжают в описания. ItemStack без износа. Одно поле места и item\_move. Версия сохранения +1.
