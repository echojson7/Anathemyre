# Сторонние библиотеки

Правило отбора — в CLAUDE.md, раздел «Жёсткие требования к стеку» (2026-10-30). Коротко: библиотека
нужна под задачу, которая уже на очереди; лицензия MIT, zlib, BSD, Apache-2.0 или public domain; C или
C-интерфейс, исходники в `third_party/`, сборка нашим Makefile; в шаге мира не участвует; спрятана за
нашим тонким слоем. Каждую согласует пользователь.

## Подключены

Пока ни одной. Рантайм игры: libc, POSIX, X11/Win32, Vulkan через драйвер, ALSA/winmm.

## Кандидаты: когда и зачем

| Библиотека | Лицензия | Язык | Задача | Когда брать | Цена |
|---|---|---|---|---|---|
| zstd | BSD | C | сжатие сохранений и журнала мира | когда сохранение вырастет за ~10 МБ (сейчас 0.4 МБ) | ~1 МБ кода, сохранение 3–5× меньше, запись быстрее диска |
| lz4 | BSD-2 | C | быстрое сжатие для фонового сохранения и кеша чанков | вместе с фоновым сохранением | очень мало кода, сжатие слабее zstd |
| SDL3 | zlib | C | окно, ввод, геймпады, Steam Deck, macOS, Wayland | при порте на macOS или поддержке геймпадов | DLL рядом с игрой; заменяет platform_*.c и audio_*.c |
| Tracy | BSD-3 | C++ с C-интерфейсом | таймлайн потоков и GPU: где ждут потоки, что тормозит в битве | **только отладочная сборка**, к битвам на 500–1000 воинов и потоку симуляции | один .cpp в отладке, в релизе нет ни строки |
| Steamworks SDK | своя, бесплатно | C++ с C-интерфейсом | достижения, облако, мастерская модов | к релизу | исключение из правила лицензий, за своим слоем |
| volk | MIT | C | загрузка функций Vulkan | только если решим делать бэкенд Vulkan | один файл |

## Офлайн-инструменты (tools/, можно любые свободные)

| Библиотека | Лицензия | Зачем |
|---|---|---|
| cgltf | MIT | читать glTF из CC0-паков и MakeHuman в конвертере .mesh/.anim |
| meshoptimizer | MIT | упрощение сеток для LOD, порядок вершин под кеш GPU |
| stb_image | MIT / public domain | если появятся картинки-источники для .tex |

## Рассмотрены и не нужны

| Библиотека | Почему нет |
|---|---|
| miniaudio | свой вывод звука 132 строки на ОС уже работает; при порте звук закроет SDL3 |
| glm, cglm | своя math3d.h, 176 строк; узкое место не в математике |
| Jolt, Box2D | своя простая физика расталкивания; Jolt на C++; понадобится разве что для рэгдоллов |
| Recast/Detour | путь решён полями направлений на отряд (docs/bands.md), сетка навигации не нужна |
| Dear ImGui | своё меню НАСТРОЙКИ в стиле игры; C++ |
| FSR, DLSS | апскейл спорит с пиксельностью; DLSS закрыт |
| GLAD, GLEW, volk | GL удалён; функции Vulkan грузит свой rb_vk.c через vkGetInstanceProcAddr |
