# Предметы: общие генераторы

Состояние на 2026-10-31. Код — `src/content/props.h`, `src/content/props.c`. План целиком (материалы, описания
объектов, заготовки, расстановка) — Claude Doc «Переиспользование вещей, объектов и материалов».

## Правило

Вид предмета пишется один раз. Разница между экземплярами — из `Rng` (размер, оттенок, износ, поворот),
а не из новых функций. Новый вид — только если он иначе играется или у него другой силуэт. Локация не пишет
свой ящик или кабель: берёт `prop_*`, а если нужного нет — добавляет его сюда.

## Что есть

| Функция | Что | Где стоит сейчас |
|---|---|---|
| `prop_crate`, `prop_crate_stack` | ящик из листа с рёбрами; стопка из 1–3 | Скудель |
| `prop_barrel` | бочка стоя или на боку, обручи | Скудель |
| `prop_sack`, `prop_sack_pile` | мешок; куча из 2–5 | Скудель |
| `prop_scrap_heap` | куча лома: листы, трубы, обломки, колёса | Скудель |
| `prop_clutter` | случайная мелочь у стены (ящики, бочки, мешки, лом) | Скудель |
| `prop_wire` | провод или кабель с провисом по параболе | Скудель, Остов |
| `prop_cable` | провод с тряпками или лампой | Скудель |
| `prop_lamp_post` | фонарь на столбе | Скудель |
| `prop_rug`, `prop_fire_pit` | ковёр; очаг с треногой и котлом | Скудель |
| `prop_water_tower` | бак на ногах с краном | Скудель |
| `prop_fence`, `prop_railing`, `prop_ladder` | забор из листов и блоков; перила из труб; лестница | Скудель |
| `prop_pipe_run` | труба по точкам вдоль стены: колена, фланцы, хомуты | Остов |
| `prop_ground` (`PROP_*`) | бревно, пень, лежачая труба, лист, шестерня, обломок плиты | долина |

Помощники в `props.h`: `prop_tint` (оттенок и износ по каналам), `prop_shade` (только яркость), `prop_pick`
(цвет из набора), `prop_box`, `prop_frame`, `prop_lbox`, `prop_lcyl`. Цвета — материалы по имени ([materials.md](materials.md)):
`prop_paint(mb, r, g_mat.rust, 0.2f)` — материал с разбросом, `prop_mat` — без, `mat_tint` — только цвет.

## Что пока осталось на месте

- Бетонные обломки Остова (`chunk`, `rubble`) — часть его системы неровного бетона (сколы, изломы, прутья).
  Переедут вместе с ней, когда появится кит построек (этап 3 плана).
- Цвета, которые есть у одной вещи (бочки, канистры, мелочь прилавков), — числа в генераторе. Общие стали
  материалами (этап 2, [materials.md](materials.md)); эти переедут вместе с вещью на этапе 3.
