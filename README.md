# Anathemyre

Открытый мир с живой симуляцией фракций. Чистый C11, без движка и сторонних библиотек в рантайме: окно, ввод, загрузка OpenGL, рендер и пост-обработка написаны с нуля. Правила проекта в [CLAUDE.md](CLAUDE.md).

![Зал](docs/stage0-1.png)

## Сейчас: этап 0, тестовая комната

- Платформы: Linux (X11 + GLX, libGL через `dlopen`) и Windows (Win32 + WGL, opengl32.dll через `LoadLibrary`). Контекст OpenGL 4.5 core, свой загрузчик функций GL.
- Рендер в полном разрешении окна, размер пикселя задаёт глубина по одному правилу: обычно блок 2x2, у самой камеры 4x4 (пиксель мира не мельче 1/80 м), вдали пиксель кадра (при отдалении пиксельность не растёт). Поверхности как текстуры низкого разрешения: материал и свет считаются квадратами 1/10 м мира.
- Тени от низкого солнца, высотный туман, объёмные лучи, затенение углов.
- Пост-обработка: грязный грейд, виньетка, плёночное зерно.
- Процедурная сцена: бетонный зал с колоннадой, руины, трубы, резервуар, знаки неизвестного языка, мегаструктуры у горизонта.
- Процедурные фигуры (~4 тыс. треугольников): капюшон, респиратор, снаряжение, скелет из 11 костей, GPU-скиннинг, процедурная ходьба.
- RTS-камера.

## Сборка и запуск

Нужны компилятор C, make и заголовки X11:

```sh
# Ubuntu / Debian
sudo apt install build-essential libx11-dev
# Fedora
sudo dnf install gcc make libX11-devel
# Arch
sudo pacman -S base-devel libx11
```

```sh
make            # релиз -> build/anathemyre
make run        # собрать и запустить
make debug      # отладка с ASan/UBSan -> build/anathemyre_debug
make run-debug
```

Быстрый цикл после правок: `./tools/run.sh` подтягивает свежий код текущей ветки, собирает и запускает игру. `./tools/run.sh имя-ветки` сначала переключается на ветку; аргументы после неё уходят игре, например `./tools/run.sh --novsync`.

### Windows

Есть нативная версия: окно Win32, контекст WGL, только системные DLL. Три способа:

1. **Из WSL (проще всего, если WSL уже стоит).** `sudo apt install mingw-w64`, затем `./tools/run.sh`: скрипт сам соберёт `build/anathemyre.exe` и запустит его в Windows.
2. **MSYS2.** В терминале «MSYS2 UCRT64»: `pacman -S git make mingw-w64-ucrt-x86_64-gcc`, затем `./tools/run.sh`.
3. **Готовый exe.** Артефакт `anathemyre-windows` в CI на GitHub (вкладка Actions): распаковать и запустить `build/anathemyre.exe`.

Linux-версия в WSL тоже работает, но медленнее: кадр идёт через трансляцию D3D12 и композитор WSLg. Для неё `tools/run.sh` ставит `GALLIUM_DRIVER=d3d12`, иначе рисует процессор (`llvmpipe` в строке `GL:`). Принудительно Linux-версия: `ANA_TARGET=linux ./tools/run.sh`. Нативный порт Win32 + WGL будет отдельным этапом.

## Управление

| Клавиша | Действие |
|---|---|
| WASD, стрелки | сдвиг камеры (Shift — быстрее) |
| Q / E, средняя кнопка мыши | поворот и наклон |
| Колесо | дистанция |
| ЛКМ | выбрать своего (Shift — добавить), протяжка — рамка; по бойцу арены — осмотр |
| ПКМ по земле | выбранные идут туда строем |
| Карточка внизу | выбрать; двойной щелчок — камера к нему |
| Z / X / C | выбранные: шаг / трусца / бег (или кнопки на панели слева внизу) |
| G | держать строй |
| I | инвентарь выбранного (Esc или × — закрыть) |
| P | персонаж: тело по частям, раны, навыки |
| В инвентаре: ЛКМ / ПКМ по вещи | взять и положить / надеть или снять |
| Пробел | пауза; кнопки вверху справа — скорость ×1 / ×2 / ×3 |
| F | камера следует за первым выбранным |
| НАСТРОЙКИ (кнопка слева вверху) | отладочное меню: фильтр кадра, пиксельность, vsync, сутки, камера следует, люди для сравнения, время суток, скорость, кадр в мс, перезагрузка шейдеров, замер кадра, журнал |
| Esc | закрыть окно, иначе выход |

## Параметры командной строки

```
--size W H                  размер окна
--seed N                    зерно мира
--novsync                   без vsync (для замеров)
--follow                    камера следует за отрядом
--inspect                   выбрать отряд и открыть осмотр (для снимков)
--cam X Z YAW PITCH DIST    положение камеры
--shot file.ppm [--frames N] снять кадр и выйти
```

## Замер производительности

Каждые 2 секунды в консоль пишется строка `КАДР:` с временем кадра и разбивкой: CPU (логика, отправка команд, ожидание swap) и GPU по проходам (тени, сцена, атмосфера, стиль, апскейл), по меткам времени `GL_TIMESTAMP`. Если сумма GPU сильно меньше времени кадра, узкое место не в рендере, а в CPU, драйвере или выводе окна.

## Структура

```
src/core/      арены, RNG, время, лог, математика
src/platform/  окно, ввод, GL-контекст (platform_linux.c, platform_win32.c)
src/render/    загрузчик GL, геометрия, рендерер
src/game/      тестовая комната, персонаж
data/shaders/  GLSL: сцена, атмосфера, стилизация
tools/         скрипт запуска, подавления LSan для драйвера
```
