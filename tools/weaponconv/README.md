# Модели оружия из Blender

Офлайн-инструмент (CLAUDE.md: офлайн-инструментам сторонние программы разрешены): скрипты лепят каждую вещь
в Blender 4.x без окна и выгружают её в свой формат `.mesh`. В игру Blender не линкуется.

- `wlib.py` — общее: лофт по сечениям, трубки, фаски, материалы для листа, рендер сбоку, выгрузка.
- `resheto.py`, `vereteno.py`, `lopast.py` — уникальные вещи, по одной на скрипт.
- `onehand.py` (ЗАТОЧКА, РЕЗАК, РЕССОРА, ПОЛОСА, СЕКАЧ, ТЁСЛО), `twohand.py` (ДОЛГАЯ ПОЛОСА, ОТВАЛ, БАЛКА),
  `polearms.py` (БАГОР, КОСА, ТРУБА) — листы по семействам, в одном масштабе.
- `preview.py` — читает выгруженные `.mesh` и ставит их на лист в осях игры: проверка выгрузки.
- `sheet.py`, `label.py` — листы для сравнения с концептом.

Лист: `blender -b -P twohand.py -- out.png 48` (последнее — сэмплы Cycles).
Выгрузка всего: `tools/weaponconv/export.sh` → `data/meshes/weapons/<id>.mesh`.

Выгрузка (`export_weapon` в `wlib.py`, только при `EXPORT=папка`):
1. Кривые — в сетки, модификаторы (фаски) применяются.
2. Сетка упрощается до ~2400 треугольников (`lower_poly`: сначала слияние плоских граней, потом схлопывание рёбер).
3. Оси: в скрипте остриё по +X, лезвие по −Z, толщина по Y; в игре кулак правой руки в нуле, остриё по +Y,
   лезвие по +Z, толщина по X. Где кулак, задаёт `FIST` в скрипте (для двуручного левая рука ляжет на 0.15 м ниже,
   для древкового — на 0.62 м выше, см. `weapon_left_grip` в src/sim/anim.c).
4. Материал Blender → материал и цвет игры по `MATMAP`; в `pad1` вершины — номер детали для ржавчины по качеству.
5. Формат AMSH 1: `AMSH`, версия, число вершин и индексов, Vertex[] (32 байта, src/core/mesh.h), u32[].

Длина в `data/defs/weapons.txt` должна совпадать с расстоянием от кулака до острия модели.
