# Подсечка: удар низом по ногам из глубокого приседа (этап 11, docs/people.md «Обмен ударами»): клип CMU lunge.
# Окно удара и отмена — метки клипа (data/anims/lunge.txt)
kind strike
clip lunge
start 0
end 50          # бьющий поднялся из приседа наполовину; дальше — выход в стойку
reach 0.8 1.25  # м до цели (клинок у земли в 1.3–1.4 м от бьющего)
hitstop 5
push 0.15       # м: отброс задетого (по ногам — меньше)
react 0.7       # с: реакция задетого
line low        # по ногам: блок руками не держит, нырок не спасает — только отойти или ударить первым
