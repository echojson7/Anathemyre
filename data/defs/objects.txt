# Объекты: части построек и мелочи локаций. Что это и зачем — docs/objects.md
#
# shape имя — генератор формы (content/shapes.c и файлы локаций); без shape объект только светит
# size x y z — размер по умолчанию, м; строка put в заготовке может задать свой
# mat имя, mat2 имя — материалы слотов 0 и 1 (materials.txt); put может заменить
# tint a — разброс цвета по зерну экземпляра
# place settle|hang|fixed — как стоит (sim/phys.h); пока все стоят намертво
# shadow yes|no — отбрасывает ли тень
# solid full — коробка во весь размер (точка экземпляра — её середина);
#   solid cx cy cz hx hy hz — коробка в осях объекта при размере по умолчанию, растягивается с размером; до 4
# light материал сила | light r g b — свет (компонент); light_at, light_dir — точка и ось в осях объекта;
#   light_radius, light_cone (косинус половины угла, -1 — во все стороны), light_glow;
#   light_night a s — горит с темноты a + s·(зерно 0..1), без строки — всегда; light_flicker none|hum;
#   light_shadow yes|no — на будущее
# act что x y z поворот — точка действия (сесть, торговать): на будущее, логики нет
#
# Новый объект — только если иначе играется или у него другой силуэт; оттенок и износ — зерно экземпляра
